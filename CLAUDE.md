# CLAUDE.md

This is the source code for a macOS menu bar app that displays GitHub Actions workflow run statuses for selected repositories.

The app is:

- Built using Swift and SwiftUI
- Uses GitHub's REST API to fetch workflow run data
- Displays workflow run statuses in the macOS menu bar
- Is built with Xcode
- Is distributed through the Mac App Store
